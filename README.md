# XLPro 📊

XLPro ek Android Spreadsheet App hai, jo PC wale Excel jaisa hi kaam karta hai.

Isme aap Marks, Total, Percentage, Formulas sab calculate kar sakte ho. Ye bahut halka hai, sirf 10-15 MB ka, isliye kisi bhi Android phone me fast chalega.

## Features
- PC jaisa Excel experience
- Formulas, Total, Percentage working
- Lightweight - Sirf 10-15 MB
- Android ke liye banaya gaya
